# โปรแกรมหาค่าความคลาดเคลื่อนมิเตอร์ (`MeterErrorCalc`)

[English](README.md)

แอป Streamlit สำหรับคำนวณเปอร์เซ็นต์ความคลาดเคลื่อนของมิเตอร์ไฟฟ้า โดยเปรียบเทียบค่ากำลังไฟฟ้า 3 Rate ระหว่างก่อนแก้ไขและหลังแก้ไข

## ข้อกำหนดระบบ

- Python 3
- `streamlit`, `pandas`

## ติดตั้งและใช้งาน

สร้าง virtual environment, ติดตั้งแพ็กเกจที่จำเป็น แล้วเปิดแอป Streamlit:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install streamlit pandas
streamlit run file.py
```

## การทำงานของโปรแกรม

- **แท็บก่อนแก้ไขและหลังแก้ไข**: กรอกค่า Voltage (`V`), Current (`I`) และ Power Factor (`PF`) สำหรับ `Rate A`, `Rate B` และ `Rate C` (ช่องว่างจะคิดเป็น `0.0` อัตโนมัติ)
- **การคำนวณกำลังไฟฟ้า**: คำนวณ `kW = (V * I * PF) / 1000` แยกราย Rate แล้วรวมทั้ง 3 Rate
- **แท็บสรุปผล**: คำนวณ `% Error = ((total_old / total_new) - 1) * 100` เมื่อ `total_new > 0` (หากไม่เกินจะแสดง `0.0`) พร้อมแจ้งสถานะมิเตอร์หมุนเร็ว (`> 0%`), หมุนช้า (`< 0%`) หรือเที่ยงตรง (`0%`) และแสดงตารางเปรียบเทียบราย Rate
